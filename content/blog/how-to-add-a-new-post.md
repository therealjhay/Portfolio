Creating a post is straightforward.

## 1. Create a new markdown file

Add a file in `content/blog`, for example:

```md
my-next-post.md
```

## 2. Add frontmatter

```md
---
title: "My Next Post"
date: "2026-04-17"
summary: "What this article is about."
tags:
  - Web3
  - React
---
```

## 3. Write content

Use normal Markdown for headings, links, lists, and code blocks.

## 4. Save and deploy

Your post automatically appears on `/blog` and at `/blog/my-next-post`.
